ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบแบ่งเขตเลือกตั้ง)
ส.ส. ๕/๑๗
ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) สุริยะ ประธานกรรมการนับคะแนนบัตรเลือกตั้ง
( ว่าที่รอง ผู้อำนวยการ หัวหน้าส่วน )

(ลงชื่อ) โสภารา กรรมการนับคะแนนบัตรเลือกตั้ง (ลงชื่อ) รัตติกาล กรรมการนับคะแนนบัตรเลือกตั้ง
( นายสาวโสภารา แสนไพบูลย์ ) (นางสาวรัตติกาล ปินทองธรรม)

(ลงชื่อ) ธิดา กรรมการนับคะแนนบัตรเลือกตั้ง (ลงชื่อ) วันจิตรา กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาวธิดา ลุงลานุ่ม ) (นางสาววันจิตรา วงศ์เหล็ก)

(ลงชื่อ) โภชนูไทย กรรมการนับคะแนนบัตรเลือกตั้ง (ลงชื่อ) กวินธิดา กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาวโภชนูไทย มณฑิ ) (นางสาวกวินธิดา พลมานพ์)

(ลงชื่อ) เวียงฤทธิ์ กรรมการนับคะแนนบัตรเลือกตั้ง (ลงชื่อ) สมพร กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาววรัญญูชัย รักข์เจริญใจแก้ว ) (นางสาวพลพรม ปัญจะ )

( สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )

หมายเหตุ : ส.ส. ๕/๑๗ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
