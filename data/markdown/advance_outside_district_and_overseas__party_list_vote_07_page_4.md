ส.ส. ๕/๑๗(บช)
สีขาว

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) สุรัตน์ ประธานกรรมการนับคะแนนบัตรเลือกตั้ง
( ว่าที่ ร.ต. สุรินทร์ จุฬาภิรมย์ )

(ลงชื่อ) ธรรมการนับคะแนนบัตรเลือกตั้ง กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาวโสติกา แสนใจมาล )
(ลงชื่อ) ธิดา กรรมการนับคะแนนบัตรเลือกตั้ง กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาวธิดา คงพานม )
(ลงชื่อ) โกญโญโย กรรมการนับคะแนนบัตรเลือกตั้ง กรรมการนับคะแนนบัตรเลือกตั้ง
( นางรา โกญโญโย ชมพู )
(ลงชื่อ) วังกฤษฎีห์ กรรมการนับคะแนนบัตรเลือกตั้ง กรรมการนับคะแนนบัตรเลือกตั้ง
( นางสาวจรัญฤทธิ์ ขักโกปิญา )

( สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )

หมายเหตุ : ส.ส. ๕/๑๗ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
