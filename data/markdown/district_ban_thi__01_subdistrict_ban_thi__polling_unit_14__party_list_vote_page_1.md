ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 14 หมู่ที่ 13 ตำบล/แขวง/เทศบาล บ้านธิ อำเภอ/เขต บ้านธิ เขตเลือกตั้งที่ 1 จังหวัด ล่าสุด เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 400 คน ( ครึ่ง )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 339 คน ( ครบถ้วนตามที่เสนอ )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 400 บัตร ( ครึ่ง )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ 339 จำนวน 317 บัตร ( ไม่ครบถ้วนตามที่เสนอ )
๒.๒.๑ บัตรดี 317 จำนวน 317 บัตร ( ไม่ครบถ้วนตามที่เสนอ )
๒.๒.๒ บัตรเสีย 17 จำนวน 17 บัตร ( ไม่ครบถ้วนตามที่เสนอ )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 171 บัตร ( ครึ่ง )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 61 บัตร ( ไม่ครบถ้วนตามที่เสนอ )
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
