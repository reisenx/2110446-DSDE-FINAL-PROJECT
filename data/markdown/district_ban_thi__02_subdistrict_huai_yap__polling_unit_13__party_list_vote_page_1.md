ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 13 หมู่ที่ 13 ตำบล/แขวง/เทศบาล ห้วยขวาง อำเภอ/เขต บ้านถิ่น เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 525 คน ( หัวข้อยย์ลิงห้า )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 427 คน ( สุริยะลิปเก็ต )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 520 บัตร ( หัวข้อยย์ลิงห้า )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 427 บัตร ( สุริยะลิปเก็ต )
๒.๒.๑ บัตรดี จำนวน 396 บัตร ( สามร้อยหกสิบเก้าสิบเก้า สุริยะลิปเก็ต )
๒.๒.๒ บัตรเสีย จำนวน 20 บัตร ( สองสิบ )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 561 บัตร ( สิบสามเอ็ด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 939 บัตร ( เก้าสิบสาม เก้าสิบเจ็ด )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
