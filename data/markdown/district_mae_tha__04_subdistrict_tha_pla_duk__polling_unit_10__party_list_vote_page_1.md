ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๗ เดือน กุมภาพันธ์ พ.ศ. ๒๕๖๙ เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ ๑๐ หมู่ที่ ๙ ตำบล/แขวง/เทศบาล ท่าปลาดุก อำเภอ/เขต แม่ทา เขตเลือกตั้งที่ ๑ จังหวัด สระบุรี เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน ๔๔๔ คน ( ครึ่งรอบสิบสี่คน )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน ๓๒๒ คน ( ครึ่งรอบสิบสองคน )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน ๔๖๐ บัตร ( สี่ร้อยหกสิบบัตร )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน ๓๔๒ บัตร ( สามร้อยสี่สิบสองบัตร )
๒.๒.๑ บัตรดี จำนวน ๒๘๔ บัตร ( สองร้อยแปดสิบสี่บัตร )
๒.๒.๒ บัตรเสีย จำนวน ๑๖ บัตร ( สิบหกบัตร )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน ๒๒ บัตร ( ยี่สิบสองบัตร )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน ๑๓๘ บัตร ( หนึ่งร้อยสามสิบแปดบัตร )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
