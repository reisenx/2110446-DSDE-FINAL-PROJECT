ส.ส. ๕/๑๘
สีขาว

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) สุนทร ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายสาวลาวัลย์ ธนันชัย )

(ลงชื่อ) สุนทร มาลาพันธ์ กรรมการประจำหน่วยเลือกตั้ง
(นายสมพร มาลาพันธ์)

(ลงชื่อ) อภิชาติ ทิพย์ทอง กรรมการประจำหน่วยเลือกตั้ง
( นายธานินท์ กำธร )

(ลงชื่อ) จิราภรณ์ เหลาพันธ์สลัก กรรมการประจำหน่วยเลือกตั้ง
( นายวิชาญ เหลาพันธ์สลัก )

(ลงชื่อ) พัชราภรณ์ กลั่นประโคน กรรมการประจำหน่วยเลือกตั้ง
( นายพันธราภรณ์ กลั่นประโคน )

(ลงชื่อ) ณรงค์ โยธาใหม่ กรรมการประจำหน่วยเลือกตั้ง
( นางสาวจิรากุล โยธาใหม่ )

(ลงชื่อ) วิภา จินดาศัด กรรมการประจำหน่วยเลือกตั้ง
( นางสาวมนทิรา จินดาศัด)

สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน

หมายเหตุ : ส.ส. ๕/๑๘ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
