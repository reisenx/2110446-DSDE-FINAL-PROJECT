ส.ส. ๕/๑๘(บช)
สีขาว

ประกาศ ณ วันที่ ๒ เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) อาฟินี ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายสาวทิพย์ ธนันชัย )

(ลงชื่อ) สุภาพร มาลาฤาษี กรรมการประจำหน่วยเลือกตั้ง
( นายสมุทร มาลาสุเทพ )
(ลงชื่อ) อภิชาติ ภัทรา กรรมการประจำหน่วยเลือกตั้ง
( นายธานันท์ ถ้ำทาศ )
(ลงชื่อ) จิราพร เหลามณีสิงห์ กรรมการประจำหน่วยเลือกตั้ง
( นายวิทย เหลานิมล )
(ลงชื่อ) พิชชากร คลั่งประโคน กรรมการประจำหน่วยเลือกตั้ง
( นายณัฐวารรณ์ กลั่นปะโคน )

(ลงชื่อ) ภัทรา กรรมการประจำหน่วยเลือกตั้ง
( นายอดุล เหลานิมลัก )
(ลงชื่อ) ศรีสันติ ใจอน กรรมการประจำหน่วยเลือกตั้ง
( นายสาวพวงจันทร์ ใจนอน )
(ลงชื่อ) จิราวุธ โยธาใหม่ กรรมการประจำหน่วยเลือกตั้ง
( นายสาววิภากร โยธาใหม่ )
(ลงชื่อ) มณฑิรา กรรมการประจำหน่วยเลือกตั้ง
( นางสาวมนทิมา จินดาจิต )

สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน

หมายเหตุ : ส.ส. ๕/๑๘ (บข) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
