สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 2 หมู่ที่ 2 ตำบล/แขวง/เทศบาล ท่าขมเงิน อำเภอ/เขต แม่จา เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 426 คน ( ที่ร้องยื่นสิบหก )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 344 คน ( สามร้อยสี่สิบสี่ )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 440 บัตร ( ที่ร้องสี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 344 บัตร ( สามร้อยสี่สิบสี่ )
๒.๒.๑ บัตรดี จำนวน 238 บัตร ( สองร้อยเก้าสิบแปด )
๒.๒.๒ บัตรเสีย จำนวน 15 บัตร ( สิบห้า )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 31 บัตร ( สามสิบเอ็ด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 96 บัตร ( เก้าสิบหก )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
