ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๒ เดือน กุมภาพันธ์ พ.ศ. ๒๕๖๓ เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ ๓ หมู่ที่ ๒ ตำบล/แขวง/เทศบาล ศาลาแดง อำเภอ/เขต บางจาก เขตเลือกตั้งที่ ๑ จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 483 คน ( ส่วนมากสิบห้า )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 365 คน ( ส่วนย่อยหกสิบห้า )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 480 บัตร ( ส่วนใหญ่ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 365 บัตร ( ส่วนย่อยหกสิบห้า )
๒.๒.๑ บัตรดี จำนวน 325 บัตร ( ส่วนย่อยสิบห้า )
๒.๒.๒ บัตรเสีย จำนวน 14 บัตร ( สิบสี่ )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 26 บัตร ( ยี่สิบหก )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 115 บัตร ( หนึ่งร้อยสิบห้า )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
