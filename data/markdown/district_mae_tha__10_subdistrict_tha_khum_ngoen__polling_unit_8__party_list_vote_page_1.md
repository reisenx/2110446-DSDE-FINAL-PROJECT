# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 8 หมู่ที่ 7 ตำบล/แขวง/เทศบาล กำแพงเพชร อำเภอ/เขต กำแพงเพชร เขตเลือกตั้งที่ 1 จังหวัด กำแพงเพชร เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 420 คน ( ที่มีอายุน้อยกว่า 30 ปี )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 356 คน ( ที่มีอายุน้อยกว่า 30 ปี )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 420 บัตร ( ที่มีอายุน้อยกว่า 30 ปี )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้
๒.๒.๑ บัตรดี จำนวน 356 บัตร ( ที่มีอายุน้อยกว่า 30 ปี )
๒.๒.๒ บัตรเสีย จำนวน 213 บัตร ( ที่มีอายุน้อยกว่า 30 ปี )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 22 บัตร ( ที่มีอายุน้อยกว่า 30 ปี )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 64 บัตร ( ที่มีอายุน้อยกว่า 30 ปี )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
