ส.ส. ๕/๑๘

# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

สีขาว

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 4 หมู่ที่ 4 ตำบล/แขวง/เทศบาล ท่าแสม อําเภอ/เขต แม่ทา เขตเลือกตั้งที่ 1 จังหวัด สุราษฎร์ธานี เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง 324 คน
๒. จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 324 คน
๓. จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 282 คน
๔. จำนวนบัตรเลือกตั้ง 282 ใบ
๕. จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 340 ใบ
๖. จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 282 ใบ
๗. จำนวนบัตรเลือกตั้งที่ไม่ได้ใช้ จำนวน 268 ใบ
๘. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 41 ใบ
๙. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 15 ใบ
๑๐. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 3 ใบ
๑๑. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 4 ใบ
๑๒. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 7 ใบ
๑๓. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 58 ใบ
๑๔. จำนวนบัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 1 ใบ

๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 340 ใบ ( ลงชื่อร้อยยี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 282 ใบ ( ลงชื่อ นายแปดสิบสอง )
๒.๒.๑ บัตรดี จำนวน 268 ใบ ( ลงชื่อ นายหลักสามสิบแปด )
๒.๒.๒ บัตรเสีย จำนวน 41 ใบ ( ลงชื่อ นายสิบเก้า สี่สิบเก้า )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 15 ใบ ( ลงชื่อ นายสิบห้า สี่สิบห้า )
๒.๒.๔ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 3 ใบ ( ลงชื่อ นายสาม )
๒.๒.๕ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 4 ใบ ( ลงชื่อ นายแปด )
๒.๒.๖ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 7 ใบ ( ลงชื่อ นายสิบแปด )
๒.๒.๗ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 58 ใบ ( ลงชื่อ นายสิบแปด )
๒.๒.๘ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 1 ใบ ( ลงชื่อ นายแปด )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
