# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

สีขาว

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 12 หมู่ที่ 8 ตำบล/แขวง/เทศบาล ต้นธง อำเภอ/เขต เมือง
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 678 คน ( หกรณ์ แจ้ง สิบแปด )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 528 คน ( หรวัชระ สิงห์แปด )

๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 640 บัตร ( หกรณ์ แจ้ง สิบแปด )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 528 บัตร ( หรวัชระ ยี่สิบแปด )
    ๒.๓ บัตรดี จำนวน 435 บัตร ( สุริยะ แจ้ง สิงห์ )
    ๒.๔ บัตรเสีย จำนวน 24 บัตร ( - ยี่สิบสี่ - )
    ๒.๕ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 29 บัตร ( - ยี่สิบเก้า - )
    ๒.๖ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 112 บัตร ( หรวัชระ แจ้ง สิงห์ )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
