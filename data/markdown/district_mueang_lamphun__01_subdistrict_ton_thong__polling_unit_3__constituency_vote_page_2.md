ส.ส. ๕/๑๘
สีขาว

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569

(ลงชื่อ) สุนิตา ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายสุพัตรา ดวงแก้วกลาง )

(ลงชื่อ) คมลิน จันทรวิชัย กรรมการประจำหน่วยเลือกตั้ง
( นายคมลิน จันทะวัง )

(ลงชื่อ) วรรณพร ประจักษ์ กรรมการประจำหน่วยเลือกตั้ง
( นางวนพรรณ อินทมาภรณ์ )

(ลงชื่อ) ชาญณรงค์ ธรรมการประจำหน่วยเลือกตั้ง
( น.ส.รุติกาญจน์ นามาฏ )

(ลงชื่อ) สายใจ กรรมการประจำหน่วยเลือกตั้ง
( นายสายใจ หาดง )

(ลงชื่อ) มีธร อิสรภาพ กรรมการประจำหน่วยเลือกตั้ง
( นายมังกร อิศราภพ.)

( สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )

หมายเหตุ : ส.ส. ๕/๑๘ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
