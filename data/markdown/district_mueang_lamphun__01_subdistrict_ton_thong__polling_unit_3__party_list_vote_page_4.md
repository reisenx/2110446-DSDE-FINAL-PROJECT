ส.ส. ๕/๑๘(บช)
สีขาว

ขุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบบัญชีรายชื่อ)
ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567

(ลงชื่อ) สุพตรา ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายสุพตรา อรรถกันตก )

(ลงชื่อ) คมสิน จันทะวิง กรรมการประจำหน่วยเลือกตั้ง
( นายคมสิน จันทะวิง )

(ลงชื่อ) วรรณพรชน อินทรค่ายา กรรมการประจำหน่วยเลือกตั้ง
( นางวรรณพรชน อินทรค่ายา )

(ลงชื่อ) น.ส.ชาภานนท์ นามธง กรรมการประจำหน่วยเลือกตั้ง
( น.ส.ชาภานนท์ นามธง )

(ลงชื่อ) มี. กรรมการประจำหน่วยเลือกตั้ง
( นายประพัฒน์ ภันทาธร )

(ลงชื่อ) พล คุณธรรมการประจำหน่วยเลือกตั้ง
( นายพลพิพัฒน์ อุดมสม )

(ลงชื่อ) นายนิรนุช ทองสว่าง กรรมการประจำหน่วยเลือกตั้ง
( นางนิรนุช ทองสว่าง )

(ลงชื่อ) สายใจ กรรมการประจำหน่วยเลือกตั้ง
( นางสายใจ นาถ )

(ลงชื่อ) มังกร อิสรภาพ กรรมการประจำหน่วยเลือกตั้ง
( นางมังกร อิสรภาพ )

สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน

หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
