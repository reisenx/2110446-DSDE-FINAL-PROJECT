# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 12 หมู่ที่ 8 ตำบล/แขวง/เทศบาล บ้านกลาง อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 604 คน ( หกร้อยสี่สิบสี่ )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 458 คน ( สี่ร้อยห้าสิบแปด )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 580 บัตร ( ห้าร้อยแปดสิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 458 บัตร ( สี่ร้อยห้าสิบแปด )
๒.๒.๑ บัตรดี จำนวน 425 บัตร ( สี่ร้อยยี่สิบห้า )
๒.๒.๒ บัตรเสีย จำนวน 12 บัตร ( สิบสอง )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 21 บัตร ( ยี่สิบเอ็ด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 122 บัตร ( หนึ่งร้อยยี่สิบสอง )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
