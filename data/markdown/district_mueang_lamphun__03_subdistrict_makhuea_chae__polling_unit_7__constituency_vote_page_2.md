ส.ส. ๕/๑๘
สีขาว

ประกาศ ณ วันที่ 8 เดือน ก.พ. พ.ศ. 2567

(ลงชื่อ) ประทานกรรมการประจำหน่วยเลือกตั้ง
( นายอาทิตย์ อนุกูลอนันต์ )

(ลงชื่อ) จิติมา กรรมการประจำหน่วยเลือกตั้ง
( นางสาวจิติมา กรุงเวศ )

(ลงชื่อ) มาลัย กรรมการประจำหน่วยเลือกตั้ง
( นางมาลัย สุขบูรณ์ )

(ลงชื่อ) ศิริพร กรรมการประจำหน่วยเลือกตั้ง
( นางศิริพร อินชัย )

(ลงชื่อ) ราตรี กรรมการประจำหน่วยเลือกตั้ง
( นางราตรี ดวงลาภ )

(ลงชื่อ) นฤมล กรรมการประจำหน่วยเลือกตั้ง
( นางนฤมล แสงสุรินทร์ )

(ลงชื่อ) สุพล กรรมการประจำหน่วยเลือกตั้ง
( นางสาวสุพล ตันตา )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน)

หมายเหตุ : ส.ส. ๕/๑๘ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
