ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๕ เดือน กุมภาพันธ์ พ.ศ. ๒๕๖๙ เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ ๑๐ หมู่ที่ ๑ ตำบล/แขวง/เทศบาล สีเขียว อำเภอ/เขต ถลาง
เขตเลือกตั้งที่ ๑ จังหวัด ภูเก็ต เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 426 คน ( สีเขียว นิสินแดง )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 339 คน ( สีชมพู สามสีเหลือง )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 400 บัตร ( สีเขียว )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 339 บัตร ( สีชมพู สามสีเหลือง )
๒.๒.๑ บัตรดี จำนวน 312 บัตร ( สีชมพู สามสีเหลือง )
๒.๒.๒ บัตรเสีย จำนวน 17 บัตร ( สีชมพู สามสีเหลือง )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 13 บัตร ( สีชมพู สามสีเหลือง )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 61 บัตร ( สีชมพู สามสีเหลือง )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
