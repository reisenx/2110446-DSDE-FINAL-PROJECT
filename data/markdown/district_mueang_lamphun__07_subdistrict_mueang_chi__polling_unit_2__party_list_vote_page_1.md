ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 2 หมู่ที่ 1 ตำบล/แขวง/เทศบาล เหมือง อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 438 คน ( ที่ถือยานพาหนะ )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 344 คน ( ตามบัญชีที่ 1 )
๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 420 บัตร ( ที่ถือยานพาหนะ )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 420 บัตร ( ที่ถือยานพาหนะ )
    ๒.๒.๑ บัตรดี จำนวน 310 บัตร ( ตามบัญชีที่ 2 )
    ๒.๒.๒ บัตรเสีย จำนวน 18 บัตร ( สิทธิตามบัญชี )
    ๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 22 บัตร ( มีใบแจ้งเงินคืนส่ง )
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 324 บัตร ( ตามบัญชีที่ 3 คิดสิบห้าบาท )
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
