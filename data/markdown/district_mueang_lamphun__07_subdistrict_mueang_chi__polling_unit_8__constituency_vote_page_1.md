สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้ใช้การเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 8 หมู่ที่ 7 ตำบล/แขวง/เทศบาล เหมืองจี อำเภอ/เขต เมืองลำพูน
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 454 คน ( สำรองห้าสิบสี่คน )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 366 คน ( สามร้อยหกสิบหกคน)
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 420 บัตร ( สำรองยี่สิบบัตร )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 366 บัตร ( สามร้อยหกสิบหกบัตร )
๒.๒.๑ บัตรดี จำนวน 320 บัตร ( สามร้อยยี่สิบบัตร )
๒.๒.๒ บัตรเสีย จำนวน 19 บัตร ( สิบเก้า )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 27 บัตร ( ยี่สิบเจ็ด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 54 บัตร ( ห้าสิบสี่บัตร )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
