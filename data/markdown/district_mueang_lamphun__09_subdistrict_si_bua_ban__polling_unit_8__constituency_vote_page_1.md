สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 4 หมู่ที่ 5 ตำบล/แขวง/เทศบาล ตรังแพรกษา อำเภอ/เขต เพ็ง
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 572 คน ( ห้าร้อยเจ็ดสิบสอง )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 490 คน ( สี่ร้อยเก้าสิบคน )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 560 บัตร ( ห้าร้อยหกสิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้
๒.๒.๑ บัตรดี จำนวน 490 บัตร ( สี่ร้อยเก้าสิบ )
๒.๒.๒ บัตรเสีย จำนวน 451 บัตร ( สี่ร้อยห้าสิบเอ็ด )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 20 บัตร ( ยี่สิบ )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 19 บัตร ( ยี่สิบเก้า )
๒.๔ จำนวนผู้สมัครที่ไม่มีบัตรเลือกตั้ง จำนวน 40 บัตร ( ห้าสิบ )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
