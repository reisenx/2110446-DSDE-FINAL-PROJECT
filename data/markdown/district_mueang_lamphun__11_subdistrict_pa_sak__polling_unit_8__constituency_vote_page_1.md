# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

สีขาว

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567 เป็นวันเลือกตั้ง นั้น

ปัตนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 8 หมู่ที่ 6 ตำบล/แขวง/เทศบาล ไทรฮ่า อําเภอ/เขต 1000
เขตเลือกตั้งที่ 1 จังหวัด สิงห์บุรี เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 640 คน ( หัวใจสี่สิน )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 537 คน ( หัวใจสามสิบเจ็ด )

๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 620 บัตร ( หัวใจยี่สิบ )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 537 บัตร ( หัวใจสามสิบเจ็ด )
    ๒.๒.๑ บัตรดี 481 จำนวน 495 บัตร ( หัวใจเก้าสิบห้า หัวใจแปดสิบเอ็ด )
    ๒.๒.๒ บัตรเสีย 14 จำนวน 12 บัตร ( หัวใจสองสิบสี่ )
    ๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด 42 จำนวน 30 บัตร ( สามสิบสี่สิบสอง)
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ 83 จำนวน 45 บัตร ( สี่สิบสาม แปดสิบสาม)

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
