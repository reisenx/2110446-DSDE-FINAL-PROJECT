สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
ปิดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 7 หมู่ที่ 7 ตำบล/แขวง/เทศบาล ม้าสัก อำเภอ/เขต เมตตา เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๓. จำนวนผู้มีสิทธิเลือกตั้ง
๓.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 678 คน ( หกร้อยเจ็ดสิบแปด )
๓.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 543 คน ( ห้าร้อยสี่สิบสาม )
๔. จำนวนบัตรเลือกตั้ง
๔.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 660 บัตร ( หกร้อยหกสิบ )
๔.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 549 บัตร ( ห้าร้อยสี่สิบสาม)
๔.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 459 บัตร ( สี่ร้อยห้าสิบเก้า)
๔.๔ บัตรเสีย จำนวน 78 บัตร ( สองสิบแปด)
๔.๕ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 47 บัตร ( สี่สิบเจ็ด)
๔.๖ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 117 บัตร ( หนึ่งร้อยสิบเจ็ด)
๕. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
