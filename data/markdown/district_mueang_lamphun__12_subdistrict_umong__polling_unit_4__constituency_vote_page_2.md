ส.ส. ๕/๑๘
สีขาว

ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบแบ่งเขตเลือกตั้ง)
ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569

(ลงชื่อ) ประยุทธ์ ประธานกรรมการประจำหน่วยเลือกตั้ง
( นางชิดยา อับดี )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) นริชาพร จาริสุวรรณ กรรมการประจำหน่วยเลือกตั้ง
( นางนริชาพร จาริสุวรรณ )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) พรวิไล มิตรมากร กรรมการประจำหน่วยเลือกตั้ง
( นางพรวิไล มิตรมากร )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) พรเทพ สุขุมภูมิ กรรมการประจำหน่วยเลือกตั้ง
( นางพรเทพ สุขุมภูมิ )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) พรเทพ สุขุมภูมิ กรรมการประจำหน่วยเลือกตั้ง
( นางพรเทพ สุขุมภูมิ )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน)

หมายเหตุ : ส.ส. ๕/๑๘ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
