ส.ส. ๕/๑๘
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 5 หมู่ที่ 4 ตำบล/แขวง/เทศบาล คูโมงค์ อำเภอ/เขต เมืองลำพูน
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 539 คน ( ห้าร้อยสามสิบเก้า )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 443 คน ( สี่ร้อยสี่สิบสาม )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 520 บัตร ( ห้าร้อยยี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 443 บัตร ( สี่ร้อยสี่สิบสาม )
๒.๒.๑ บัตรดี จำนวน 379 บัตร ( สามร้อยเจ็ดสิบเก้า )
๒.๒.๒ บัตรเสีย จำนวน 24 บัตร ( สี่สิบสี่ )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 40 บัตร ( สี่สิบ )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 77 บัตร ( เจ็ดสิบเจ็ด )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
