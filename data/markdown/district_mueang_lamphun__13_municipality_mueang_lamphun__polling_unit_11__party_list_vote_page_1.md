# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 11 หมู่ที่ - ตำบล/แขวง/เทศบาล ในเมือง อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด กำแพงเพชร เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 605 คน ( หกร้อยห้าสิบห้าคน )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 491 คน ( สี่ร้อยเก้าสิบเอ็ดคน )

๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( หกร้อยบัตร )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 491 บัตร ( สี่ร้อยเก้าสิบเอ็ดบัตร )
    ๒.๒.๑ บัตรดี จำนวน 459 บัตร ( สี่ร้อยห้าสิบเก้าบัตร )
    ๒.๒.๒ บัตรเสีย จำนวน 9 บัตร (เก้าบัตร)
    ๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 23 บัตร ( ยี่สิบสามบัตร )
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 109 บัตร ( หนึ่งร้อยเก้าบัตร )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
