# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 10 หมู่ที่ - ตำบล/แขวง/เทศบาล ไม่มีเวล อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด สระบุรี เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 647 คน ( นายชัยศักดิ์ )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 439 คน ( นิตยา สมศิริไกร )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( นภารัชย์ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 439 บัตร ( ศรีสมบูรณ์ สามสิงห์ )
๒.๒.๑ บัตรดี จำนวน 404 บัตร ( ศรีชัยยศ )
๒.๒.๒ บัตรเสีย จำนวน 9 บัตร ( เกร )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 26 บัตร ( ปะลิพนา )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 161 บัตร ( นางรัชนี นฤสิทธิ์ )
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
