ส.ส. ๕/๑๘
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้งของหน่วยเลือกตั้งที่ 2 หมู่ที่ ตำบล/แขวง/เทศบาล อำเภอ/เขต เมือง
เขตเลือกตั้งที่ 1 จังหวัด สมุทรสาคร เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 47 คน ( ที่มีอายุเกิน 30 ปี )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน คน ( )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 470 บัตร ( ที่มีอายุเกิน 30 ปี )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 351 บัตร ( ตามทะเบียนบ้าน )
๒.๒.๑ บัตรดี จำนวน 314 บัตร ( ที่มีอายุเกิน 30 ปี )
๒.๒.๒ บัตรเสีย จำนวน 8 บัตร ( หมดอายุ )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 29 บัตร ( ยกเว้น )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 89 บัตร ( แฟกซ์ )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
