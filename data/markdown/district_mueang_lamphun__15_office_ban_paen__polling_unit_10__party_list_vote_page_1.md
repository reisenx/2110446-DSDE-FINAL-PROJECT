# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 6 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 10 หมู่ที่ 6 ตำบล/แขวง/เทศบาล บ้านเป็น อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 466 คน ( สำรองตกสิบแปดคนเช่น )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 310 คน ( สามร้อยหกสิบคนเช่น )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 440 บัตร ( สี่ร้อยสี่สิบบัตรถ้วน )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 360 บัตร ( สามร้อยหกสิบบัตรถ้วน )
๒.๒.๑ บัตรดี จำนวน 327 บัตร ( สามร้อยสองสิบเจ็ดบัตรถ้วน (รวมออกสิบเครื่อง) )
๒.๒.๒ บัตรเสีย จำนวน 4 บัตร ( เลื่อนบัตรถ้วน )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 17 บัตร ( อิงค์จุดบัตรถ้วน )

๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 80 บัตร ( แปดสิบเก้า)

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
