สีขาว

ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบบัญชีรายชื่อ)
ส.ส. ๕/๑๘(บช)

ประกาศ ณ วันที่ 8 เดือน ก.พ. พ.ศ. 2569
(ลงชื่อ) วิทยา ประทาน ประธานกรรมการประจำหน่วยเลือกตั้ง
( ปัญญาฯ ใจดี )

(ลงชื่อ) ทินทอง หัวแหน็ง กรรมการประจำหน่วยเลือกตั้ง
( ทินทอง หัวแหน็ง )
(ลงชื่อ) นิยมล ขวัญคำ กรรมการประจำหน่วยเลือกตั้ง
( นิยมล ขวัญคำ )
(ลงชื่อ) จิรมา ยะพร อัย กรรมการประจำหน่วยเลือกตั้ง
( จารุมา ยะพร อัย )
(ลงชื่อ) การาวรรณ์ ศรีจัง กรรมการประจำหน่วยเลือกตั้ง
( การาวรรณ์ ศรีจัง )

(ลงชื่อ) จามจุรี มั่นสมบุญ กรรมการประจำหน่วยเลือกตั้ง
( จามจุรี มั่นสมบุญ )
(ลงชื่อ) ภัคดา โกไกทอง กรรมการประจำหน่วยเลือกตั้ง
( ภัคดา โกไกทอง )
(ลงชื่อ) อนุชา ปัญญาภา กรรมการประจำหน่วยเลือกตั้ง
( อนุชา ปัญญาภา )
(ลงชื่อ) สัมฤทธิ์ นิลพฤกษ์ กรรมการประจำหน่วยเลือกตั้ง
( สัมฤทธิ์ นิลพฤกษ์ )

( สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )

หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
