ส.ส. ๕/๑๘(บช)
สีขาว

ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบบัญชีรายชื่อ)

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569

(ลงชื่อ) ประธานกรรมการประจำหน่วยเลือกตั้ง
(น.ส.เนาวรัตน เชียงคายลา )

(ลงชื่อ) กัลยมั่นไค้าตาภา กรรมการประจำหน่วยเลือกตั้ง
(น.ส.กัลยมั่นไค้าตาภา )

(ลงชื่อ) สุวรรณรัตน คำบุญเรือง กรรมการประจำหน่วยเลือกตั้ง
(น.ส.สุวรรณรัตน คำบุญเรือง )

(ลงชื่อ) นิรัตน์ญา เพ็งเย็น กรรมการประจำหน่วยเลือกตั้ง
(น.ส.นิรัตน์ญา เพ็งเย็น )

(ลงชื่อ) นางนวลจารี พงคลาง กรรมการประจำหน่วยเลือกตั้ง
(นางนวลจารี พงคลาง )

(ลงชื่อ) อังคนา ไทยกรรณ กรรมการประจำหน่วยเลือกตั้ง
(อังคนา ไทยกรรณ )

(ลงชื่อ) เจนณรงค์ กาญยะ กรรมการประจำหน่วยเลือกตั้ง
(นายเจนณรงค์ กาญยะ )

(ลงชื่อ) นางอำพนธ์ รัฐมศุภ กรรมการประจำหน่วยเลือกตั้ง
(นางอำพนธ์ รัฐมศุภ )

(ลงชื่อ) น.ส.โสภ กำศักดิ์ กรรมการประจำหน่วยเลือกตั้ง
(น.ส.โสภ กำศักดิ์ )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )

หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
