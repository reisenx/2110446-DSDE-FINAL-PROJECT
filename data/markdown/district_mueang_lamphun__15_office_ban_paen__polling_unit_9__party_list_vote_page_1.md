# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 2 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 9 หมู่ที่ 3 ตำบล/แขวง/เทศบาล ท่าแซ่น อำเภอ/เขต 609 เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 658 คน ( หกร้อยห้าสิบแปดคน )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 495 คน ( สี่ร้อยเก้าสิบห้าคน )

๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 640 บัตร ( หกร้อยสี่สิบบัตร )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 495 บัตร ( สี่ร้อยเก้าสิบห้าบัตร )
    ๒.๒.๑ บัตรดี จำนวน 497 บัตร ( สี่ร้อยสามสิบเก้าบัตร )
    ๒.๒.๒ บัตรเสีย จำนวน 27 บัตร ( สี่สิบเจ็ดบัตร )
    ๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 29 บัตร ( ยี่สิบเก้าบัตร )
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 145 บัตร ( หนึ่งร้อยสี่สิบห้าบัตร )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
