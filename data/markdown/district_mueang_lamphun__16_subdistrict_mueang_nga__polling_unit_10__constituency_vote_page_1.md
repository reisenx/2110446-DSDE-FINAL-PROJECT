# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

สีขาว

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 20 หมู่ที่ 5 ตำบล/แขวง/เทศบาล เหลืองง่า อำเภอ/เขต เมืองกำแพง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 633 คน ( หกร้อยสามสิบสาม )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 488 คน ( สี่ร้อยแปดสิบแปด )
๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( หกร้อย )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 488 บัตร ( สี่ร้อยแปดสิบแปด )
    ๒.๒.๑ บัตรดี จำนวน 426 บัตร ( สี่ร้อยยี่สิบหก )
    ๒.๒.๒ บัตรเสีย จำนวน 33 บัตร ( สามสิบสาม )
    ๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 29 บัตร ( ยี่สิบเก้า )
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 112 บัตร ( หนึ่งร้อยสิบสอง )
๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
