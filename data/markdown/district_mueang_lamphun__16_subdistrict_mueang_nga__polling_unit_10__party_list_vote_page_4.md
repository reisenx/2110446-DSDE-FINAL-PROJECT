ส.ส. ๕/๑๘(บช)
สีขาว

ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบบัญชีรายชื่อ)
ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569

(ลงชื่อ) อาทิตยา เทพวรรณ ประธานกรรมการประจำหน่วยเลือกตั้ง
( อาทิตยา เทพวรรณ )

(ลงชื่อ) ทองสม ภิรมย์ กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) สิรานี กรรมการประจำหน่วยเลือกตั้ง
( ทองสม ภิรมย์ ) ( นางสิรานี เทพเมือง )

(ลงชื่อ) อั้นใจ กำแก้ว กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) จิรวัฒน์ กรรมการประจำหน่วยเลือกตั้ง
( อั้นใจ กำแก้ว ) ( จิรวัฒน์ )

(ลงชื่อ) ชาญพร พินนาตา กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) สุขสม ลิมโพธิ์ กรรมการประจำหน่วยเลือกตั้ง
( ชาญพร พินนาตา ) ( สุขสม ลิมโพธิ์ )

(ลงชื่อ) วิไลน์ ชัยมงคล กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) สุรพล ศิลาดำ กรรมการประจำหน่วยเลือกตั้ง
( วิไลน์ ชัยมงคล ) ( สุรพล ศิลาดำ )

( สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน )
หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
