ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน ก.พ. พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 4 หมู่ที่ 2 ตำบล/แขวง/เทศบาล เหมือง อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 634 คน ( หกร้อยสามสิบสี่ )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 504 คน ( ห้าร้อยสี่ )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 620 บัตร ( หกร้อยยี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 504 บัตร ( ห้าร้อยสี่ )
๒.๒.๑ บัตรดี จำนวน 476 บัตร ( สี่ร้อยเจ็ดสิบหก )
๒.๒.๒ บัตรเสีย จำนวน 14 บัตร ( สิบสี่ )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 14 บัตร ( สิบสี่ )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 116 บัตร ( หนึ่งร้อยสิบหก )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
