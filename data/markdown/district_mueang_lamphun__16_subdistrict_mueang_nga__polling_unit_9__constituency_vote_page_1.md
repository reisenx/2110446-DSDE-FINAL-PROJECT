รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 9 หมู่ที่ 5 ตำบล/แขวง/เทศบาล เหมืองอำ อำเภอ/เขต เมืองลำพูน
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 634 คน ( หกร้อยสามสิบสี่ )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 495 คน ( สี่ร้อยเก้าสิบห้า )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( หกร้อย )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 495 บัตร ( สี่ร้อยเก้าสิบห้า )
๒.๒.๑ บัตรดี จำนวน 443 บัตร ( สี่ร้อยสี่สิบสาม )
๒.๒.๒ บัตรเสีย จำนวน 19 บัตร ( สิบเก้า )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 33 บัตร ( สามสิบสาม )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 103 บัตร ( หนึ่งร้อยห้า )
๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
