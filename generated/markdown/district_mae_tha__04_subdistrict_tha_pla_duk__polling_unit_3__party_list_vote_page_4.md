สีขาว

ชุดที่ ๑ เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง (แบบบัญชีรายชื่อ)
ส.ส. ๕/๑๘(บช)

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) สุลักษณ์ ประธานกรรมการประจำหน่วยเลือกตั้ง
( สุลักษณ์ ฤกษ์ธมฺม )

(ลงชื่อ) ธรรมการประจำหน่วยเลือกตั้ง ผ่องศรี เหม่ามาลา
( ผ่องศรี เหม่ามาลา )

(ลงชื่อ) ประภัย กรรมการประจำหน่วยเลือกตั้ง ประภัย ถาไผ่
( ประภัย ถาไผ่ )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง ปรินทร์ สมใจใหญ่
( ปรินทร์ สมใจใหญ่ )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง ปฐมพร สิทธิจุก
( ปฐมพร สิทธิจุก )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง วรรธนพร ตาพงศ์
( วรรธนพร ตาพงศ์ )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง ลิชัย ฟูศรี
( ลิชัย ฟูศรี )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง เจตริน โมลาดุก
( เจตริน โมลาดุก )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง นารพัฒน์ มุกดาช
( นารพัฒน์ มุกดาช )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน)

หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
