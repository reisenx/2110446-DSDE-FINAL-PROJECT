# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

สีขาว

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 7 หมู่ที่ 6 ตำบล/แขวง/เทศบาล ทุปลำอุก อำเภอ/เขต แม่ทา เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน ของ หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 623 คน ( นางยิมยี่สังสามคน )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 446 คน ( สี่ร้อยสี่สิบหกคน )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 640 บัตร ( หกร้อยสี่สิบบัตร )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 446 บัตร ( สี่ร้อยสี่สิบหกบัตร )
๒.๒.๑ บัตรดี จำนวน 406 บัตร ( สี่ร้อยหกบัตร )
๒.๒.๒ บัตรเสีย จำนวน 18 บัตร ( สิบแปดบัตร )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 22 บัตร ( ยี่สิบสองบัตร )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 194 บัตร ( หนึ่งร้อยเก้าสิบสี่บัตร )

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
