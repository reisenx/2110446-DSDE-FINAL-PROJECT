ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๗ เดือน กุมภาพันธ์ พ.ศ. ๒๕๖๙ เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ ๗ หมู่ที่ ๑๐ ตำบล/แขวง/เทศบาล ททท. อำเภอ/เขต แม่ทา เขตเลือกตั้งที่ ๑ จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน ๔๑๘ คน ( สิ่งสืบค้นแปล )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน ๓๗๒ คน ( สามร้อยเจ็ดสิบสอง)
๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน ๔๑๘ บัตร ( สิ่งสืบค้นแปล สิ่งสืบยึด)
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน ๓๗๒ บัตร ( สามร้อยเจ็ดสิบสอง)
    ๒.๒.๑ บัตรดี จำนวน ๓๓๑ บัตร ( สามร้อยสามสิบเอ็ด)
    ๒.๒.๒ บัตรเสีย จำนวน ๒๗ บัตร ( ยี่สิบเจ็ด)
    ๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน ๒๒ บัตร ( สิบสี่)
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน ๔๘ บัตร ( สี่สิบแปด)
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
