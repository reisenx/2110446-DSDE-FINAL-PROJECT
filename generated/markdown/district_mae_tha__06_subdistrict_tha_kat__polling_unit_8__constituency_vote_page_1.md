# รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๘ เดือน กุมภาพันธ์ พ.ศ. ๒๕๖๔ เป็นวันเลือกตั้ง นั้น

บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ ๗ หมู่ที่ ๑๑ ตำบล/แขวง/เทศบาล ทากาศ อำเภอ/เขต แม่ตา
เขตเลือกตั้งที่ ๑ จังหวัด สุพรรณบุรี เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของ หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน ๒๑๗ คน (สองร้อยสิบเจ็ดคน)
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน ๑๙๙ คน (หนึ่งร้อยเก้าสิบเก้า)

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน ๒๒๐ บัตร (สองร้อยยี่สิบ)
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน ๑๘๙ บัตร (หนึ่งร้อยแปดสิบห้า)
๒.๓ บัตรตี จำนวน ๑๑๑ บัตร (หนึ่งร้อยหกสิบเอ็ด)
๒.๔ บัตรเสีย จำนวน ๓ บัตร (สาม)
๒.๕ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน ๒๑ บัตร (ยี่สิบเอ็ด)
๒.๖ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน ๓๙ บัตร (สามสิบห้า)

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
