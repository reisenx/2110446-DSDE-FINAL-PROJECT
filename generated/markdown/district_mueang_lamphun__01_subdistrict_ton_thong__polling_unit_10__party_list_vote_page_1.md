ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 10 หมู่ที่ 7 ตำบล/แขวง/เทศบาล ต้นสูง อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 100 คน ( หัวใจ )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 3 คน ( สามร้อยเก้าสิบแปด )
๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 70 บัตร ( หัวใจ )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 70 บัตร ( สามร้อยเก้าสิบแปด )
    ๒.๓ บัตรดี จำนวน 70 บัตร ( สามร้อยเก้าสิบแปด )
    ๒.๔ บัตรเสีย จำนวน 10 บัตร ( สิบสอง )
    ๒.๕ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 4 บัตร ( สี่สิบสี่ )
    ๒.๖ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 102 บัตร ( หนึ่งร้อยสอง )
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
