สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบแบ่งเขตเลือกตั้ง

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎร แบบแบ่งเขต เลือกตั้งของหน่วยเลือกตั้งที่ 15 หมู่ที่ 11 ตำบล/แขวง/เทศบาล ตนเอง อำเภอ/เขต เมือง
เขตเลือกตั้งที่ 1 จังหวัด ลำพูน เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนน หน่วยเลือกตั้งดังกล่าว ดังนี้

๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 573 คน ( นำร้อยเจ็ดสิบสาม )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 444 คน ( สี่ร้อยสี่สิบสี่ )

๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 540 บัตร ( นำร้อยสี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 444 บัตร ( ศรีร้อยสี่สิบสี่ )
๒.๒.๑ บัตรดี จำนวน 385 บัตร ( สามร้อยแปดสิบห้า )
๒.๒.๒ บัตรเสีย จำนวน 12 บัตร ( สิบสอง )
๒.๒.๓ บัตรที่ไม่เลือกผู้สมัครผู้ใด จำนวน 47 บัตร ( สี่สิบเจ็ด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 96 บัตร (เก้าสิบหกบัตร)

๓. จำนวนคะแนนที่ผู้สมัครรับเลือกตั้งแต่ละคนได้รับเรียงตามลำดับหมายเลขประจำตัวผู้สมัคร
