ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ ๙ เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 9 หมู่ที่ 6 ตำบล/แขวง/เทศบาล ค่ายลง อำเภอ/เขต เมืองกำแพงเพชร เขตเลือกตั้งที่ 1 จังหวัด กำแพงเพชร เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 62 คน ( พร้อมที่สิ้นสุด )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 508 คน ( พร้อมที่สิ้นสุด )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( พร้อมที่สิ้นสุด )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 508 บัตร ( พร้อมที่สิ้นสุด )
๒.๒.๑ บัตรดี จำนวน 452 บัตร ( พร้อมที่สิ้นสุด )
๒.๒.๒ บัตรเสีย จำนวน 42 บัตร ( พร้อมที่สิ้นสุด )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 23 บัตร ( พร้อมที่สิ้นสุด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 92 บัตร ( พร้อมที่สิ้นสุด )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
