ส.ส. ๕/๑๘(บช)
สีขาว

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) Chalermchai ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายชาลี อินกล้า )

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง สุริมาอารักษ์
( สมขวัญ จันทากลาส )

(ลงชื่อ) ปภัสรา กรรมการประจำหน่วยเลือกตั้ง
( ปภัสรา เป็งล้าง )

(ลงชื่อ) ธรรมการประจำหน่วยเลือกตั้ง พรหมพงศ์
( ภิชาติ เจริญสมบุญ )

(ลงชื่อ) ธรรมการประจำหน่วยเลือกตั้ง นิตยา พรหมวงศ์
( พงษ์ศิริ เยืองวงค์ )

(ลงชื่อ) ธรรมการประจำหน่วยเลือกตั้ง พรโชค
( พ.ล.พรโชค แก้วสัก )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน)

หมายเหตุ : ส.ส. ๕/๑๘ (บช) จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
