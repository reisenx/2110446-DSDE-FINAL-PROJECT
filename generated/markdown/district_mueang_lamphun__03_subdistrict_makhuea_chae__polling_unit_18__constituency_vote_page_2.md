ส.ส. ๕/๑๘ สีขาว

ประกาศ ณ วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2569
(ลงชื่อ) ศุภวิทย์ ประธานกรรมการประจำหน่วยเลือกตั้ง
( นายศุภวิทย์ มูลเชียง )

(ลงชื่อ) อนุชิตน์ กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) อุดิน กรรมการประจำหน่วยเลือกตั้ง
( อนุชิตน์ ) ( อดิน ตันมาก )

(ลงชื่อ) ภัทราภรณ์ กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) ณัฐภพ กรรมการประจำหน่วยเลือกตั้ง
( ภัทราภรณ์ ) ( ณัฐภพ จันทร์ )

(ลงชื่อ) ธนิดา กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) เลิศ กรรมการประจำหน่วยเลือกตั้ง
( ธนิดา ใจงาม ) ( เลิศ สมบัติ อินทน)

(ลงชื่อ) กรรมการประจำหน่วยเลือกตั้ง (ลงชื่อ) แสงธรรม กรรมการประจำหน่วยเลือกตั้ง
( ดวงจันทร์ ) ( แสงธรรม )

(สำหรับระบุเหตุที่ผลการนับคะแนนเลือกตั้งปรากฏจำนวนผู้มาใช้สิทธิเลือกตั้งไม่ตรงกับจำนวนบัตรเลือกตั้งที่ใช้ออกเสียงลงคะแนน)
หมายเหตุ : ส.ส. ๕/๑๘ จัดทำจำนวน ๓ ชุด
๑. ปิดประกาศ ณ ที่เลือกตั้ง จำนวน ๑ ชุด
๒. ใส่ถุงวัสดุใสซึ่งบรรจุบัตรเลือกตั้งที่นับเป็นคะแนนแล้ว จำนวน ๑ ชุด
๓. เก็บไว้ในเล่มเพื่อส่งคณะกรรมการการเลือกตั้งประจำเขตเลือกตั้ง จำนวน ๑ ชุด
