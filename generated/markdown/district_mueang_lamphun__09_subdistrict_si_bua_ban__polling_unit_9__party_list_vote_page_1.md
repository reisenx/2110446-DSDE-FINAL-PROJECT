ส.ส. ๕/๓๘ (บข)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กุมภาพันธ์ พ.ศ. 2567 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 9 หมู่ที่ 6 ตำบล/แขวง/เทศบาล ตรังแพรกษา อำเภอ/เขต เมือง เขตเลือกตั้งที่ 1 จังหวัด แพรกษา เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
    ๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 117 คน ( เห็ดร้อยเจ็ดสิบเจ็ด )
    ๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 103 คน (หกร้อยสามสิบ )
๒. จำนวนบัตรเลือกตั้ง
    ๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 719 บัตร ( เห็ดร้อยหกสิบ )
    ๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 453 บัตร (หกร้อยห้าสิบสาม)
    ๒.๒.๑ บัตรดี จำนวน 393 บัตร ( ห้าร้อยเก้าสิบสาม )
    ๒.๒.๒ บัตรเสีย จำนวน 41 บัตร ( สี่สิบเอ็ด )
    ๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 19 บัตร ( ยี่สิบเก้า )
    ๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 197 บัตร (หนึ่งร้อยเจ็ด)
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
