สิ่งพิมพ์ออกจากระบบสำนวนความอิเล็กทรอนิกส์ ถือเป็นสำเนา
ยุทธศักราช ๒๕๖๘
คดีที่ ๓/๒๕๖๘
(นายวิริยะ เข็มทอง)
ต.ต. ๕/๑๘ (บช.)
รายจ่ายผลการปักคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 2 เดือน กุมภาพันธ์ พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 1 หมู่ที่ 1 ตำบล/แขวง/เทศบาล ปากเกร็ด อำเภอ/เขต เมือง
เขตเลือกตั้งที่ 1 จังหวัด กำแพงเพชร เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 859 คน ( แปดร้อยห้าสิบเก้า )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 760 คน ( แปดร้อยหกสิบ )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 840 บัตร ( แปดร้อยสี่สิบ )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 760 บัตร ( แปดร้อยหกสิบ )
๒.๒.๑ บัตรตี จำนวน 199 บัตร ( หกร้อยเก้าสิบเก้า )
๒.๒.๒ บัตรเสีย จำนวน 21 บัตร ( สองสิบเอ็ด )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 40 บัตร ( สี่สิบ )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 80 บัตร ( แปดสิบ )

๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
