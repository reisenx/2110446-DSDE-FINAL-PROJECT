ส.ส. ๕/๑๘ (บช)
สีขาว

รายงานผลการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อ

ตามที่ได้มีพระราชกฤษฎีกาให้มีการเลือกตั้งสมาชิกสภาผู้แทนราษฎร และคณะกรรมการการเลือกตั้ง ได้กำหนดให้วันที่ 8 เดือน กพ. พ.ศ. 2569 เป็นวันเลือกตั้ง นั้น
บัดนี้ คณะกรรมการประจำหน่วยเลือกตั้งได้ดำเนินการนับคะแนนสมาชิกสภาผู้แทนราษฎรแบบบัญชีรายชื่อของหน่วยเลือกตั้งที่ 6 หมู่ที่ 3 ตำบล/แขวง/เทศบาล 10101 อำเภอ/เขต 1200
เขตเลือกตั้งที่ 1 จังหวัด สุพรรณฯ เสร็จสิ้นเป็นที่เรียบร้อยแล้ว ดังนั้น จึงขอรายงานผลการนับคะแนนของหน่วยเลือกตั้งดังกล่าว ดังนี้
๑. จำนวนผู้มีสิทธิเลือกตั้ง
๑.๑ จำนวนผู้มีสิทธิเลือกตั้งตามบัญชีรายชื่อผู้มีสิทธิเลือกตั้ง จำนวน 658 คน ( หกล้านแปด )
๑.๒ จำนวนผู้มีสิทธิเลือกตั้งที่มาแสดงตน (เฉพาะวันเลือกตั้ง) จำนวน 474 คน ( สี่ร้อยเจ็ดสิบสี่ )
๒. จำนวนบัตรเลือกตั้ง
๒.๑ จำนวนบัตรเลือกตั้งที่ได้รับจัดสรร จำนวน 600 บัตร ( หกร้อย )
๒.๒ จำนวนบัตรเลือกตั้งที่ใช้ จำนวน 474 บัตร ( สี่ร้อยเจ็ดสิบสี่ )
๒.๒.๑ บัตรดี จำนวน 429 บัตร ( สี่ร้อยยี่สิบเก้า )
๒.๒.๒ บัตรเสีย จำนวน 27 บัตร ( สี่เอ็ด )
๒.๒.๓ บัตรที่ไม่เลือกบัญชีรายชื่อของพรรคการเมืองใด จำนวน 18 บัตร ( สิบแปด )
๒.๓ จำนวนบัตรเลือกตั้งที่เหลือ จำนวน 196 บัตร ( หนึ่งร้อยสี่สิบหก )
๓. จำนวนคะแนนที่พรรคการเมืองแต่ละพรรคได้รับเรียงตามลำดับหมายเลขของบัญชีรายชื่อของพรรคการเมือง
